# 90-Day Plan

This is a recommended sequence from the stated company methodology and go-to-market. It is **not** a commitment to dates, headcount, spend, or feature work.

The founder must approve timing, when building starts, and which clinics enter a pilot.

## Operating loop (do not skip)

Research → Customer discovery → Problem validation → Product specification → Smallest possible MVP → Real customer → Measure results → Customer feedback → Iterate → Repeat

## Days 1–30 — Research, discovery, validation

**Goal:** Confirm the problem in real clinics before writing a product spec as if it were settled.

- Visit premium private dental clinics in Casablanca and Marrakech.
- Speak with owners and front desk. Observe inquiry handling.
- Identify missed inquiries, slow responses, weak follow-up, and failed booking.
- Record evidence. Do not invent features from the visits.
- Sell only as far as the founder is ready: conversation, observation, and (if appropriate) a future pilot — not a scaled campaign.

**Do not:** build the application, add verticals, or run mass Instagram outreach as the main motion.

## Days 31–60 — Spec, smallest MVP, first real use

**Goal:** Specify only the defined MVP, then put it in front of a real clinic if the problem is validated.

- Product specification is written in `blueprint/Spec/`. Treat it as approved.
- Implement only if the founder asks to implement — smallest slice that can run a 14-day pilot.
- Offer a measured pilot (~14 days) to a clinic that matches the ICP.

**Do not:** expand scope, build PMS/CRM/voice/agents, or start billing infrastructure unless required for the MVP.

## Days 61–90 — Measure, feedback, iterate

**Goal:** Prove or disprove financial value. Iterate only on repeated need.

- Measure: response time, inquiries, qualified inquiries, appointments, deposits, follow-ups, conversion.
- Review results with the clinic owner in revenue terms, not AI activity.
- Collect feedback. Change the product only where customers repeatedly need it.
- Repeat discovery and sales in the same cities. Sell before scaling.

**Do not:** optimize for message volume, add advanced reporting, or expand country/vertical.

## What this plan does not decide

The product spec is approved. The founder still decides:

- when implementation starts
- how many clinics to visit or pilot
- paid vs complimentary pilots
- exact prices inside the stated ranges

## Success for the first 90 days

Not “product launched.”

Success is **evidence**: a validated conversion problem, a specified (and only if approved, built) MVP, and — if a pilot ran — measured movement toward deposited consultations generated through Selaren.
